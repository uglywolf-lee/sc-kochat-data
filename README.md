# 스타시티즌 한글 채팅 (SC-KoChat)

스타시티즌 채팅창에 **한글을 그대로 치는** 프로그램입니다.
게임을 하면서 창을 바꾸지 않고, 한영키만 눌러 한글로 말하면 됩니다.

## 되는 것

- **한글 입력** — 한영키를 누르고 평소처럼 치면 채팅에 한글이 들어갑니다
- **자동 번역** — 같은 글을 영어로 바꿔 보낼 수 있습니다. **인터넷 없이 PC 안에서** 돕니다
- **게임 화면도 한국어** — 임무·설명·대사 9만 줄을 한국어로 바꿔 줍니다
- **함선·지명은 영어 그대로** — `리클레이머` 라고 쳐도 `Reclaimer` 로 나갑니다.
  그래야 상대가 검색해서 퀀텀 점프를 할 수 있습니다

## 두는 자리 — **설치가 아닙니다**

`SC-KoChat.exe` **하나**만 받으시면 됩니다. 폴더를 하나 만들어 거기 넣고 실행하십시오.
받는 것(한국어 번역 11MB, 번역 모델 621MB)이 **그 폴더 안에** 쌓입니다.

```
E:\Roberts Space Industries\SC-KoChat\SC-KoChat.exe      ← 게임 옆이 편합니다
```

- 관리자 권한이 필요 없고, 레지스트리·시작메뉴·`Program Files` 에 아무것도 안 남습니다
- ⚠️ **폴더 이름에 한글을 쓰지 마십시오** — 번역 모델이 경로의 한글을 못 읽습니다
- ⚠️ **게임 폴더 「안」에는 넣지 마십시오** — 게임이 패치될 때 지워집니다

처음 켜면 번역과 모델을 받느라 몇 분 걸립니다. 그다음부터는 바로 뜹니다.

## 쓰는 법

게임을 켜 두고 `SC-KoChat.exe` 를 실행해 두십시오.

```
Enter          채팅창을 연다
한영키          한글 모드로 (화면 오른쪽 아래에 작은 칸이 뜹니다)
안녕하세요       친다 — 그 칸에 보입니다
  Enter          한글로 보냄
  Shift+Enter    한글 + 영어를 한 줄에
  Ctrl+Enter     영어로만
Enter          한 번 더 눌러 전송
```

**엔터를 두 번** 누르는 것이 요령입니다. 첫 엔터에 글이 채팅창에 나타나고,
눈으로 확인한 뒤 둘째 엔터로 보냅니다.

> 치는 동안에는 게임 채팅창에 안 보입니다. 오른쪽 아래 작은 칸에는 실시간으로 보입니다.

## 상대가 한글로 보려면

받는 사람도 이 프로그램이 깔려 있어야 **한글로** 보입니다. 없으면 `@B1B8@C1B6` 처럼 보입니다.
그래서 **모르는 사람에게는 `Shift+Enter`(병기)나 `Ctrl+Enter`(영어)** 를 쓰십시오.

## 끄기 · 지우기

작업표시줄의 **「스타시티즌 한글 채팅」** 창에 있습니다. (Alt+Tab 으로도 나옵니다)

- **한글 채팅 종료** — 프로그램만 끕니다. 게임의 한국어는 그대로 남습니다
- **게임에서 지우기** — 게임에 넣은 한국어 번역과 입력표를 걷어냅니다.
  게임 글자가 다시 영어로 돌아갑니다. 남이 넣은 줄은 건드리지 않습니다

완전히 지우려면 [게임에서 지우기] 를 누른 뒤 그 폴더를 지우면 끝입니다.

화면 오른쪽 아래 작은 손잡이의 `✕` 로도 끌 수 있습니다. 손잡이는 끌어서 옮길 수 있습니다.

## 잘 안 될 때

| 이런 때 | 이렇게 |
|---|---|
| 한영키를 눌러도 한글이 안 됨 | 게임 창이 앞에 있어야 작동합니다. 키보드에 따라 오른쪽 Alt 가 한영키입니다 |
| 채팅에 `@B0A1` 같은 것이 나옴 | **게임을 다시 켜십시오.** 게임은 켤 때 번역 파일을 한 번만 읽습니다 |
| 게임 글자가 `@어쩌구` 로 뜸 | 위와 같습니다. 게임을 다시 켜면 됩니다 |
| 번역이 안 됨 | 폴더 이름에 한글이 있는지 보십시오 |
| 게임 조작키가 안 먹음 | 한글 모드가 켜진 채입니다. `Esc` 나 한영키로 빠져나오십시오 |
| 키가 이상하게 씹힘 | 프로그램이 두 개 떠 있을 수 있습니다. 다시 켜면 알아서 하나만 남습니다 |

## 게임 패치가 오면

게임이 패치되면 한국어 파일이 지워집니다. **프로그램을 다시 켜면 알아서 다시 넣습니다.**
따로 하실 일은 없습니다.

## 만든 것에 대해

- 게임 원문(CIG 저작물)은 이 저장소에 넣지 않습니다. 한국어 번역만 내려받아 씁니다
- 번역은 로컬 모델로 만들었습니다. 남의 번역을 가져다 쓰지 않았습니다
