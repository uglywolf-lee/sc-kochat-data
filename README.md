게임을 하면서 창을 바꾸지 않고, 한영키만 눌러 한글로 말하면 됩니다.

## 되는 것

- **한글 입력** — 한영키를 누르고 평소처럼 치면 채팅에 한글이 들어갑니다
- **자동 번역** — 구글 번역으로 같은 글을 영어로 바꿔 보낼 수 있습니다 (인터넷이 필요합니다)
- **게임 화면도 한국어** — 임무·설명·대사 9만 줄을 한국어로 바꿔 줍니다 -ai 번역 다른 번역과 교체가능
- **함선·지명은 영어 그대로** — `리클레이머` 라고 쳐도 `Reclaimer` 로 나갑니다.
  지명을 영문 검색해서 퀀텀 점프를 할 수 있습니다
- **받는 채팅 읽기** — 남이 친 영어·중국어 채팅을 한국어로 보여 줍니다
- **중국어로 보내기** — 친 한글을 중국어로 옮겨 보냅니다 (Ctrl+Shift+Space)
- **「!」 찾기 — 게임 안 스시 사전** — 아이템·제작 재료·구하는 곳·도면 주는 임무를 게임을 나가지 않고 찾습니다
- **음성 명령 아톰** — 말이나 휴대폰 단추판으로 게임 키를 대신 누릅니다

## 프로그램을 두는 자리 

zip 을 풀어 나온 **`SC-KoChat` 폴더**를 아무 데나 두고, 안의 `SC-KoChat.exe` 를 실행하십시오.
받는 것(한국어 번역 파일 약 11MB)이 **그 폴더 안에** 쌓입니다.

```
E:\Roberts Space Industries\SC-KoChat\SC-KoChat.exe      ← 게임 옆이 편합니다
```

- 폴더 이름은 영문으로 두는 것을 권합니다
- ⚠️ **게임 폴더 「안」에는 넣지 마십시오** — 게임이 패치될 때 지워집니다

처음 켜면 번역 파일을 받느라 잠시 걸립니다. 그다음부터는 바로 뜹니다.

## 쓰는 법

`SC-KoChat.exe` 를 **게임보다 먼저** 실행하십시오. 그다음에 게임을 켜면 됩니다.

```
Enter          채팅창을 연다
한영키          한글 모드로 (화면 오른쪽 아래에 작은 칸이 뜹니다)
안녕하세요       친다 — 그 칸에 보입니다
  Enter          한글로 보냄
  Shift+Enter    한글 + 영어를 한 줄에
  Ctrl+Enter     영어로만
Enter          한 번 더 눌러 전송
```

**엔터를 두 번** 누르는 것이 요령입니다. 첫 엔터에 글이 채팅창에 나타나고,
눈으로 확인한 뒤 둘째 엔터로 보냅니다.

> 치는 동안에는 게임 채팅창에 안 보입니다. 오른쪽 아래 작은 칸에는 실시간으로 보입니다.

## 상대가 한글로 보려면

받는 사람도 이 프로그램이 깔려 있어야 **한글로** 보입니다. 없으면 `@B1B8@C1B6` 처럼 보입니다.
그래서 **모르는 사람에게는 `Shift+Enter`(병기)나 `Ctrl+Enter`(영어)** 를 쓰십시오.

## 중국어로 보내기

한글 모드에서 글을 친 뒤 **`Ctrl+Shift+Space`** 를 누르면 중국어로 옮겨 채팅창에 넣습니다. 엔터로 보내면 됩니다.
중국어 패치를 쓰는 사람에게는 중국어로 보입니다. 우리 게임에서는 `[zh] @코드` 로 보이지만, 채팅 읽기를 켜 두면 한국어로 풀어 보여 줍니다.

## 「!」 찾기 — 게임 안 스시 사전

한글 모드에서 **맨 앞에 `!`** 를 치면 화면 오른쪽에 찾기 창이 뜹니다. (처음엔 영어 입력, 한영키로 한/영)
아이템·장비 이름, 제작 재료, 광물, 도면 주는 임무를 치고 엔터.

```
↑↓ 고르기 · 엔터/→ 들어가기 · ← 뒤로 · Esc 닫기
```

아이템 → 재료 → 구하는 곳 → 그 재료를 쓰는 다른 아이템 · 도면 주는 임무(의뢰 세력·필요 평판)로 이어 봅니다.
자료는 한글채팅 안에 들어 있어 인터넷에 연결하지 않고 찾습니다.

## 무엇이 한글로 보이고 무엇이 영어로 남나

이름은 **일부러 영어로** 둡니다. 상점·거래·퀘스트에서 **이름으로 찾아** 사고팔기 때문입니다.
한글로 옮기면 그 자리에서 검색이 안 되어 퀀텀 점프를 못 하거나 물건을 못 삽니다.
대신 **종류·크기·등급·분류는 한글**로 붙입니다.

| 무엇 | 어떤 형태로 | 예 |
|---|---|---|
| 함선 · 지명 · 상품 | **영어 그대로** | `Reclaimer` · `Hurston` · `Titanium` |
| 함선 부품 | 이름 뒤 꼬리표 (종류·크기·등급·분류) | `Bolide (파워플랜트 S2 B급 민수용)` |
| 사람 갑옷 | 등급 세 종류 | `경장갑` (Light) · `중장갑` (Medium) · `헤비갑옷` (Heavy) |
| 부품 · 장비 분류 | 꼬리표와 설명문 | `산업용` / `민수용` / `군용` / `경쟁용` / `스텔스` |
| 부품 등급 | 꼬리표와 설명문 | `A급`~`D급` · 원문이 Bespoke 인 것은 `맞춤형` · 없는 것은 비움 |

칠 때는 편하게 치시면 됩니다 — 나가는 글은 상대가 찾을 수 있는 모양으로 나갑니다.

## 끄기 · 지우기

작업표시줄의 **「스타시티즌 한글 채팅」** 창에 있습니다. (Alt+Tab 으로도 나옵니다)

- **종료**(창 맨 아래) — 프로그램만 끕니다. 게임의 한국어는 그대로 남습니다
- **게임에서 지우기**(설정 · 도움말 › 설정 탭) — 게임에 넣은 한국어 번역과 입력표를 걷어냅니다.
  게임 글자가 다시 영어로 돌아갑니다. 남이 넣은 줄은 건드리지 않습니다

완전히 지우려면 [게임에서 지우기] 를 누른 뒤 그 폴더를 지우면 끝입니다.

화면 오른쪽 아래 작은 손잡이의 `✕` 로도 끌 수 있습니다. 손잡이는 끌어서 옮길 수 있습니다.

## 잘 안 될 때

| 이런 때 | 이렇게 |
|---|---|
| 게임에 한글이 안 들어감 | 게임 폴더를 못 찾으면 작업표시줄 [스타시티즌 한글 채팅] 창 맨 위에 **「게임 폴더를 못 찾았습니다」** 줄이 뜹니다. 넣은 자리는 **설정 · 도움말 › 폴더** 탭에 보입니다. 틀렸거나 비어 있으면 **[폴더 고르기]·[폴더 바꾸기]** 로 스타시티즌이 깔린 `LIVE` 폴더를 고르십시오 (예: `E:\Roberts Space Industries\StarCitizen\LIVE`). 고른 뒤 게임을 다시 켜십시오 |
| 설치됐다는데 게임에 한국어가 안 나옴 | **게임을 다시 깔지 마십시오.** 설정 · 도움말 › 폴더 탭의 **[진단 파일]** 을 누르면 바탕화면에 `SC-KoChat_진단_날짜.txt` 가 생깁니다. 그 파일을 [Issues](https://github.com/uglywolf-lee/sc-kochat-data/issues) 에 올려 주시면 원인을 바로 찾습니다. 채팅 내용·게임 아이디는 들어 있지 않습니다 (1.7.16 부터) |
| 한영키를 눌러도 한글이 안 됨 | 게임 창이 앞에 있어야 작동합니다. 키보드에 따라 오른쪽 Alt 가 한영키입니다 |
| 채팅에 `@B0A1` 같은 것이 나옴 | **게임을 다시 켜십시오.** 게임은 켤 때 번역 파일을 한 번만 읽습니다 |
| 게임 글자가 `@어쩌구` 로 뜸 | 위와 같습니다. 게임을 다시 켜면 됩니다 |
| 채팅 번역이 안 됨 | 번역은 구글을 씁니다. 인터넷이 끊겼거나 구글이 잠시 막은 것일 수 있으니 조금 뒤에 다시 해 보십시오 |
| 게임 조작키가 안 먹음 | 한글 모드가 켜진 채입니다. `Esc` 나 한영키로 빠져나오십시오 |
| 키가 이상하게 씹힘 | 프로그램이 두 개 떠 있을 수 있습니다. 다시 켜면 알아서 하나만 남습니다 |
| 모비글라스 커뮤니티 글칸에 한글이 안 들어감 | 1.7.18 부터 됩니다. 글칸을 마우스로 누르고 한영키를 누른 뒤 치면, 엔터에 한 글자씩 쳐 넣습니다(1~2초). 그 글은 커뮤니티에서는 한글로 보이지만 **채팅창에 뜰 때는 깨져 보입니다**(게임 문제) — 채팅창에서 보이게 하려면 채팅창에서 치십시오 |
| `/agree`·`/tell` 같은 명령어가 안 먹음 | 번역 4.10.2-12(2026-11-02)에서 고쳤습니다. 프로그램은 그대로 두고 한글 채팅 → 게임 순서로 껐다 켜십시오. 명령어는 영어로 칩니다. 춤 감정표현(`/dance`)은 2026-11-05 현재 빠져 있어 쓸 수 없습니다. 「한글 패치 자동다운 안하기」를 켜 두셨으면 고친 번역이 안 들어갑니다 |
| 한글 채팅만 쓰고 게임 화면은 영어로 보고 싶음 | 작업표시줄 창 › 설정 · 도움말 › **설정** 탭에서 **「게임 글자 영어 그대로」** 를 켠 뒤 ① 한글 채팅 프로그램을 껐다 켜고 ② 게임도 껐다 켜십시오(게임은 켤 때만 글자 파일을 읽습니다). 게임에 들어 있는 영어 원문을 그대로 씁니다. 한국어로 돌아가려면 스위치를 끄고 같은 순서로 다시 켜면 됩니다 (1.7.17 부터) |

## 게임 패치가 받아지면 

게임이 패치되면 한국어 파일이 지워집니다. **프로그램을 다시 켜면 알아서 다시 넣습니다.**
따로 하실 일은 없습니다.

## 만든 것에 대해

- 게임 원문(CIG 저작물)은 이 저장소에 넣지 않습니다. 한국어 번역만 내려받아 씁니다
- 게임 화면의 한국어는 AI 번역을 바탕으로 만들었습니다. 남의 번역을 가져다 쓰지 않았습니다
- 임무 보상 표기(평판·잠재 도면·진행 점수)는 [StarStrings](https://github.com/MrKraken/StarStrings) (MrKraken) 의 자료를 영문 그대로 붙인 것입니다

## 2.0 이 오픈소스가 아닌 이유

2.0부터 소스를 공개하지 않습니다. 입력표도 배포물에 포함된 형태로만 제공합니다.

이유는 확인된 한 사례입니다. SC-KR 배포물에 우리 입력표가 그대로 들어가 있었고, 출처 표기는 없었습니다. 우리 프로젝트 이름이 붙은 표식과 버전 값까지 그대로였고, 언어팩 여러 판과 런처 실행 파일 안에서 반복 확인됐습니다.

2026-10-25 SC-KR 저장소에 출처 표기를 요청했으나([이슈 #1](https://github.com/DOKU-web/sc-kr/issues/1)), 2026-11-06 현재 답이 없습니다. 해당 블록의 출처를 밝히거나 배포물에서 제거해 주시기 바랍니다.

입력표나 데이터를 떼어 다른 프로그램·배포물에 넣는 것은 허용하지 않습니다. 받은 그대로의 원본 zip 을 무료로 나누는 것과 개인 사용은 그대로 됩니다(약관 `LICENSE.txt`). 1.7 이하 판(MIT)은 나간 그대로 남습니다.
