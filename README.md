# SC-KoChat 한국어 번역 자료

스타시티즌 한국어 번역 파일입니다. 프로그램이 여기서 받아갑니다.

| 파일 | 무엇 |
|---|---|
| `ko_global.ini` | 한국어 번역 + 부품 등급 표시 |
| `version.json` | 판 번호와 파일 정보. 프로그램이 이것만 먼저 읽습니다 |

**직접 받아 쓰셔도 됩니다.** `ko_global.ini` 를 아래에 넣고
`user.cfg` 에 `g_language = korean_(south_korea)` 한 줄을 넣으면 됩니다.

```
StarCitizen\LIVE\data\Localization\korean_(south_korea)\global.ini
```

부품 이름·함선명·지명은 **영문 그대로** 둡니다. 게임 검색창에서 찾아야 하기 때문입니다.
